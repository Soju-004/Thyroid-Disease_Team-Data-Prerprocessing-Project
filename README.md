# Thyroid Disease – Data Preprocessing Project

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) and complete data preprocessing on a Thyroid Disease dataset to prepare it for Machine Learning model training.

## Objectives
- Understand the dataset through EDA.
- Identify and handle missing values.
- Detect and treat outliers.
- Handle categorical and numerical features.
- Apply feature scaling.
- Handle class imbalance.
- Perform correlation analysis and feature selection.

## Data Preprocessing Steps

**Data Understanding:** Examining dataset dimensions, data types, statistical summaries and unique values.

**Exploratory Data Analysis (EDA):** Analysing numerical and categorical features using statistical methods and visualizations.

**Missing Value Handling:** Identifying missing values and applying suitable imputation techniques.

**Duplicate Handling:** Identifying and removing duplicate records.

**Outlier Detection and Treatment:** Detecting outliers using boxplots and the IQR method and applying suitable treatment.

**Categorical Encoding:** Converting categorical variables into numerical format using encoding techniques.

**Feature Scaling:** Applying scaling techniques to bring numerical features to a comparable range.

**Class Imbalance:** Addressing unequal target class distribution using SMOTE (Synthetic Minority Over-sampling Technique).

**Correlation Heatmap:** Visualizing relationships between features and identifying potential multicollinearity.

**Feature Selection:** Identifying relevant features for machine learning training using correlation analysis.

**Train-Test Split:** Dividing the dataset into training and testing sets for model development and evaluation.
